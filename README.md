# Jetpack Joyride Takeover

**superhot** × Jetpack Joyride · visual · idea by the team

Bring Jetpack Joyride into the game in the most visible and funny way. The change shows in the first 30 seconds of play.

> Jetpack goons, coins, zappers, lasers and missions: I strapped Jetpack Joyride onto SUPERHOT and the laser gate fried my own goons.

## Install

Install BepInEx 5 (64-bit) into your SUPERHOT folder, then copy the BepInEx folder from this mod's release folder over it and start the game. Hold SPACE in the air to fly and shoot; finish the three missions on the left for coin showers.
